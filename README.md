# 打工人的 AI 无脑教程

写给每一个想用 AI 省时间的人。不用先搞懂技术：搜一下，或者按六个板块抄，就能把 AI 用成第二双手。

**在线阅读：** https://go-mario.github.io/A-No-Brainer-AI-Guide-for-Workers/#/home

## 这是给谁的

上班要写周报、做表、回邮件的人，学生，老师，小店主，以及想帮父母用上语音助手的人。

第六板块「高手进阶」可以整章跳过。日常使用，看完前面就够。

## 里面有什么

1. **基础原理** — AI 的三个天性，什么时候好用、什么时候会编
2. **认知与提问** — 万能公式、精准 / 泛化检索、多轮打磨
3. **主流工具** — 国内外常见助手，各适合干什么，官网直达
4. **场景技巧** — 周报、邮件、PPT、英语、旅行等高频场景，三步能抄
5. **身份与模板** — 九种身份的第一课，外加八条可复制的提示词
6. **高手进阶（可跳过）** — 沉淀 Skill、定时任务、把工具串起来

首页可以搜「周报」「豆包」「英语」，直接跳到对应场景或模板。

## 离线怎么用

整个站点就是一个 `index.html`，不需要安装、构建或服务器。

1. 下载或克隆这个仓库
2. 用浏览器打开 `index.html`（双击，或拖进 Chrome / Edge / Safari）

搜索、复制提示词、六个板块之间的跳转，都在这一份文件里完成。

## 怎么贡献一个场景或模板

欢迎补一条你真的在用的场景，或一条能直接复制的提示词。

1. 先到 [Issues](https://github.com/go-Mario/A-No-Brainer-AI-Guide-for-Workers/issues) 说一下你想加什么。改动很小的话，也可以直接提 Pull Request
2. 场景写在 `index.html` 的「场景技巧」里。同时在文末脚本的 `var INDEX = [...]` 加一条可搜索条目：名称、关键词、要跳到的 `view`，以及对应元素的 `el`
3. 模板写在「身份与模板」的模板区。给 `<pre>` 一个新的 `id`（例如 `tpl-09`），复制按钮的 `data-tpl` 指向它，并在 `INDEX` 里加一条带 `copy` 字段的模板
4. 保持现在的口吻：短句、能直接抄、写明避坑。不要新开大章节

改了板块名称或跳转 id 时，记得让 `INDEX` 和页面文案一致，否则站内搜索会对不上。
